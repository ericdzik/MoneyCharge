# Guide Utilisateur - Suppression de Compte

## Comment supprimer votre compte LocaCharge

### ⚠️ Attention
La suppression de votre compte est **définitive et irréversible**. Toutes vos données seront supprimées de manière permanente.

---

## Étapes pour supprimer votre compte

### 1️⃣ Accéder à votre profil
- Ouvrez l'application LocaCharge
- Appuyez sur l'icône de profil (en bas à droite)
- Vous arrivez sur votre page de profil

### 2️⃣ Trouver la zone de suppression
- Faites défiler vers le bas de la page
- Vous verrez une section rouge intitulée **"Zone dangereuse"**
- Cette section contient le bouton **"Supprimer mon compte"**

### 3️⃣ Cliquer sur "Supprimer mon compte"
- Appuyez sur le bouton rouge
- Une fenêtre de confirmation s'affiche

### 4️⃣ Lire les conséquences
La fenêtre vous informe que la suppression entraînera :
- ❌ Suppression de toutes vos données personnelles
- ❌ Suppression de votre historique de transactions
- ❌ Suppression de vos avis et commentaires
- ❌ Perte définitive de l'accès à votre compte

### 5️⃣ Confirmer la suppression
- Pour confirmer, vous devez taper le mot **"SUPPRIMER"** (en majuscules)
- Tapez exactement : `SUPPRIMER`
- Le bouton "Supprimer définitivement" devient actif

### 6️⃣ Validation finale
- Appuyez sur **"Supprimer définitivement"**
- Un indicateur de chargement s'affiche
- Patientez pendant la suppression

### 7️⃣ Confirmation
- Un message de succès s'affiche
- Vous êtes automatiquement redirigé vers la page de connexion
- Votre compte est maintenant supprimé

---

## 🛡️ Cas particuliers

### Pour les marchands
Si vous êtes un marchand et que vous avez des **transactions en attente**, vous devrez d'abord les finaliser avant de pouvoir supprimer votre compte.

**Message d'erreur possible :**
> "Vous avez des transactions en attente. Veuillez les finaliser avant de supprimer votre compte."

**Solution :** Finalisez toutes vos transactions en cours, puis réessayez.

### Session expirée
Si votre session est trop ancienne, vous devrez vous reconnecter avant de pouvoir supprimer votre compte.

**Message d'erreur possible :**
> "Pour des raisons de sécurité, veuillez vous reconnecter avant de supprimer votre compte."

**Solution :**
1. Déconnectez-vous
2. Reconnectez-vous avec vos identifiants
3. Réessayez de supprimer votre compte

## ❓ Questions fréquentes

### Puis-je récupérer mon compte après suppression ?
**Non.** La suppression est définitive et irréversible. Aucune récupération n'est possible.

### Puis-je créer un nouveau compte avec le même email ?
**Oui.** Après la suppression, vous pouvez créer un nouveau compte avec la même adresse email, mais ce sera un compte complètement nouveau sans aucune donnée de l'ancien compte.

### Combien de temps prend la suppression ?
La suppression prend généralement **quelques secondes**. Un indicateur de chargement vous informe de la progression.

### Que se passe-t-il si j'annule pendant le processus ?
Si vous cliquez sur **"Annuler"** dans la fenêtre de confirmation, rien ne sera supprimé. Votre compte restera intact.

### Puis-je exporter mes données avant suppression ?
Actuellement, l'export automatique n'est pas disponible. Si vous souhaitez conserver vos données, contactez le support avant de supprimer votre compte.

## ⚖️ Conformité RGPD

Cette fonctionnalité respecte le **Règlement Général sur la Protection des Données (RGPD)** qui vous donne le droit de supprimer vos données personnelles.

En supprimant votre compte, vous exercez votre **droit à l'effacement** (aussi appelé "droit à l'oubli").
